# Potion Atelier — ร้านโพชั่น 16 บิต

เกมบริหารร้านโพชั่นสำหรับ Windows เขียนด้วย **Java แบบ OOP** ใช้เฉพาะ **Swing, Java2D และ Java Sound** ของ JDK ไม่มีเอนจินเกม ไม่มีไลบรารีภายนอก และเล่นออฟไลน์ได้ ใช้ภาพร้านสมุนไพร กล่องไม้ ตัวละคร และสมุนไพรจากโฟลเดอร์ `asset/` ร่วมกับขวดยาที่วาดด้วย Java2D

### ไฟล์ภาพสมุนไพร

วัตถุดิบเวทมนตร์ทั้ง 8 ชนิดแยกเป็น PNG โปร่งใสขนาด 32×32 ใน `asset/herbs/` ใช้ชุดภาพที่เลือกใหม่ทั้งหมด โดยคงแนวพิกเซลอาร์ตและแสงอุ่นให้เข้ากับร้าน ทุกหน้าที่ใช้ `PixelArt.herb` โหลดภาพชุดเดียวกัน ขยายแบบ nearest-neighbor และรวมภาพไว้ใน JAR สำหรับเล่นออฟไลน์

ดาวน์โหลดรวมได้ที่ `output/herbs/herbs-transparent-8.zip` ดูภาพรวมที่ `output/herbs/herbs-preview.png` และชื่อไฟล์ใน `output/herbs/manifest.csv` แก้ PNG ได้โดยตรงโดยไม่ถูกเขียนทับเมื่อ build หากต้องการส่งออกภาพปัจจุบันใหม่ ให้รัน `java -Djava.awt.headless=true -cp bin com.potioncraft.tools.PrepareHerbArtwork` หลัง build (คำสั่งนี้อัปเดตเฉพาะไฟล์ส่งออก ไม่เขียนทับภาพในเกม)

## เปิดเล่น

ต้องมี **Java 17 ขึ้นไป** (เครื่องนี้มี JDK 27 และได้คอมไพล์ให้รองรับ Java 17 แล้ว)

- ดับเบิลคลิก **run.bat** เพื่อเปิดเกมที่สร้างไว้ใน `dist/PotionAtelier-v2.jar`
- หลังแก้ซอร์ส ดับเบิลคลิก **compile_and_run.bat** เพื่อคอมไพล์ สร้าง JAR และเปิดเกมใหม่ ต้องใช้ JDK 17 ขึ้นไป
- เปิดจากคำสั่งได้ด้วย `java -jar dist/PotionAtelier-v2.jar`
- ใน VS Code เปิดโฟลเดอร์ `game` แล้วกด F5 เลือก `Potion Atelier` ระบบจะสร้างเกมล่าสุดก่อนเปิดทุกครั้ง

ไฟล์เปิดเกมจะตั้งโฟลเดอร์ทำงานเป็นโฟลเดอร์เกมให้อัตโนมัติ ไม่ต้องติดตั้งแพ็กเกจเพิ่ม

## ระบบเกมตามโจทย์

| รายการ | สิ่งที่มีในเกม |
|---|---|
| ลูกค้า | Common 4 คน, Rare 4 คน, Epic 3 คน, Legendary 2 คน รวม 13 คน |
| แคมเปญ | 4 บท บทละ 5 ด่าน รวม 20 ด่าน |
| ภารกิจ | 3 ข้อต่อด่าน ข้อละ 1 ดาว รวม 60 ดาว |
| เงื่อนไขผ่าน | ต้องได้อย่างน้อย 1 ดาวเมื่อจบด่าน เพื่อปลดล็อกด่านถัดไป |
| สมุนไพร | ทั้งหมด 8 ชนิด แต่ละด่านสุ่มให้ 6 ชนิด |
| สูตรยา | 24 สูตร ใช้สมุนไพรต่างชนิดอย่างน้อย 2 ชนิด สูงสุด 3 ชนิด |
| การปรุง | สกิลเช็ค 2 จังหวะต่อขวดในบท 1–2 และ 3 จังหวะในบท 3–4 |
| ปรุงพลาด | กดนอกแถบสีเขียว หรือไม่กดภายใน 5 วินาที ยาเสีย ต้องเททิ้งและปรุงใหม่ |
| ความอดทน | ลดตามเวลาจริง ระดับและนิสัยแต่ละคนมีผล เมื่อหมดจะออกจากร้าน |
| ชื่อเสียง | เริ่มด่านละ 5 แต้ม ลูกค้าออกจากร้านเสีย 1 แต้ม หมดแล้วจบด่าน |
| บันทึก | เก็บดาวสูงสุดของทุกด่านอัตโนมัติ เล่นซ้ำแล้วดาวเดิมไม่ลด |

**การตีความจำนวนสมุนไพร:** 6 หมายถึงจำนวนชนิดที่ใช้ได้ในด่าน ไม่ใช่จำนวนชิ้นรวม วัตถุดิบแต่ละชนิดมี 5 ชิ้นต่อช่อง หยิบแล้วลดจริง เมื่อหมดให้คลิกช่องหรือกดเลขช่องเพื่อเติม ใช้เวลา 3 วินาที เติมได้ไม่จำกัดรอบ สุ่มชุดวัตถุดิบด้วยเลขประจำด่าน จึงได้ชุดเดิมเมื่อเล่นซ้ำ ลูกค้าสั่งเฉพาะสูตรที่ปรุงได้จากสมุนไพรในด่านนั้น และสูตรยาทั้ง 24 สูตรมีโอกาสปรากฏในแคมเปญ

## วิธีเล่น

หม้อปรุงยาใช้ภาพโปร่งใส 4 เฟรมใน `asset/cauldron` เล่นวนเฟรมละ 180 มิลลิวินาทีตลอดเวลาที่แสดงหน้าร้าน แม้ยังไม่ได้เริ่มปรุงยา โดยไม่ขึ้นกับเวลาของด่าน

1. หน้าแรก Sweet Potion cafe แสดงพื้นหลังร้านแบบเบลอ กด **เริ่มเล่น** (หรือ ENTER) เพื่อไปเลือกแผนที่ หรือกด **ออก** เพื่อปิดโปรแกรม จากนั้นเลือกด่านบนแผนที่ อ่านภารกิจและสมุนไพร แล้วกดเปิดร้าน
2. คลิกลูกค้าเพื่อเลือกออเดอร์ ด้านขวาจะแสดงสูตรยาและนิสัยของลูกค้าคนนั้น
3. คลิกสมุนไพรตามสูตร 2–3 ชนิด ลำดับการใส่ไม่มีผล
4. เลือกลูกค้าแล้วกด SPACE เพื่อเริ่มปรุง จากนั้นกดแล้ว **ปล่อย SPACE** หรือคลิกหลอดพิกเซลเมื่อขีดอยู่ในช่วงสีเขียว ผ่านให้ครบทุกจังหวะ สุ่มจำนวนตามระดับลูกค้า: ทั่วไป 1–2, หายาก 2–3, มหากาพย์ 3–4, ตำนาน 4–5 ครั้ง ระดับสูงมีช่วงกดแคบลง พลาดหรือหมดเวลาแม้แต่ครั้งเดียวน้ำยาจะเสียทันที
5. เมื่อได้ขวดยาแล้ว คลิกลูกค้าหรือกด ENTER เพื่อเสิร์ฟให้คนที่เลือก
6. ถ้ายาเสีย กด R เพื่อเททิ้งแล้วเริ่มใหม่ สูตรที่ไม่ถูกต้องก็ทำให้ยาเสียได้เช่นกัน
7. เก็บอย่างน้อยหนึ่งดาวก่อนปิดร้าน ด่านจบเมื่อลูกค้าทั้งหมดได้รับบริการ/ออกจากร้าน เวลาหมด หรือชื่อเสียงหมด

ลูกค้ายังรอระหว่างปรุงยา เมื่อเสิร์ฟผิดจะเสียความอดทนและเสียเงื่อนไขดาวปรุงสะอาด การเสิร์ฟถูกต่อเนื่องมีโบนัสคอมโบ แต่ทำผิดหรือลูกค้าเดินออกจะตัดคอมโบ

| ปุ่ม | การทำงาน |
|---|---|
| เมาส์ | เลือกด่าน เลือกลูกค้า ใส่สมุนไพร ตรวจจังหวะ และเสิร์ฟ |
| 1–6 | ใส่สมุนไพรช่องที่ 1–6 |
| SPACE (ปล่อยปุ่ม) | เริ่มปรุง / ตรวจจังหวะ |
| TAB | เลือกลูกค้าคนถัดไป |
| ENTER | เปิดร้านในหน้าเตรียมตัว / เสิร์ฟให้ลูกค้าที่เลือก |
| R | เทยาและล้างหม้อ |
| B | เปิด/ปิดตำรายา |
| ESC | พักเกม / ปิดหน้าต่างซ้อน |

เมื่อเปิดตำรา พักเกม หรือสลับออกจากหน้าต่างเกม เวลาร้าน ความอดทนลูกค้า และสกิลเช็คจะหยุดพร้อมกัน กลับเข้าเกมแล้วกดเล่นต่อได้ ถ้ากลับแผนที่ก่อนจบด่านจะไม่บันทึกผลรอบนั้น

ตำรายาและสมุดลูกค้าใช้ไอคอนตำราเวทปกน้ำตาลตัดทอง มีจันทร์เสี้ยวและตัวล็อก เมื่อเปิดเป็นสมุดสองหน้ากระดาษสีครีม ขอบเย็บ ลายประดับ มุมทองเหลือง และที่คั่นผ้าสีเขียว พร้อมกระดาษโน้ตยื่นจากปก แถบคั่นน้ำยา/ลูกค้าด้านขวาสลับสองหมวดได้โดยเวลาร้านยังหยุดอยู่ ตำรามี 3 คู่หน้า รวม 24 สูตร พร้อมไอคอนขวดยาและสมุนไพร ส่วนบันทึกลูกค้ามี 4 คู่หน้า รวม 13 คน แสดงภาพทั้งสามอารมณ์ นิสัย และเวลารอ คลิกลูกศรบนมุมกระดาษพับขวาล่างเพื่อไปหน้าถัดไป หรือมุมซ้ายล่างเพื่อย้อนกลับ ลูกศรจะจางและกดไม่ได้เมื่อสุดหน้า กดกากบาทสีขาวที่ลอยอยู่นอกสมุดมุมขวาบนใกล้ขอบจอ หรือกด ESC เพื่อเก็บสมุดกลับเข้าร้าน

## สามดาว

ทุกด่านมีภารกิจแยกกันสามข้อ เป้าหมายเพิ่มตามบทและด่าน:

1. เสิร์ฟลูกค้าตามจำนวนที่กำหนด (อย่างน้อยครึ่งหนึ่งของลูกค้าประจำด่าน ปัดขึ้น)
2. ทำยอดขายตามเป้า โดยต้องเสิร์ฟลูกค้าสำเร็จอย่างน้อยหนึ่งคน
3. ปรุงสำเร็จตามจำนวนเป้า โดยไม่ปรุงพลาดและไม่เสิร์ฟผิดตลอดด่าน และต้องเสิร์ฟสำเร็จอย่างน้อยหนึ่งคน

ประเมินดาวเมื่อจบด่าน ดังนั้นดาวข้อสามที่ขึ้นระหว่างเล่นอาจหายได้ถ้าปรุงพลาดภายหลัง เล่นซ้ำเพื่อเก็บดาวเพิ่มได้โดยไม่เสียสถิติเดิม

## ลูกค้าและความอดทน

| ระดับ | จำนวนคน | เวลาพื้นฐาน | อัตราลดพื้นฐาน | เริ่มพบ |
|---|---:|---:|---:|---|
| Common | 4 | 30 วินาที | 1.0 เท่า | บท 1 |
| Rare | 4 | 22 วินาที | 1.1 เท่า | บท 2 |
| Epic | 3 | 15 วินาที | 1.25 เท่า | บท 3 |
| Legendary | 2 | 10 วินาที | 1.4 เท่า | บท 4 |

เวลาจริงขึ้นกับนิสัยร่วมด้วย เช่น คุณยายใจเย็น สาวน้อยเก็บเห็ดไม่ตกใจเมื่อปรุงพลาด จอมเวทฝึกหัดกับนักรบเบอร์เซิร์กเกอร์รีบร้อนขึ้นเมื่อความอดทนเหลือครึ่งหนึ่ง นักการค้าเสียความอดทนเพิ่มเมื่อยาพลาด และราชินีภูติให้โบนัสถ้าเสิร์ฟไว อ่านนิสัยเฉพาะตัวบนใบสั่งยาของลูกค้าที่เลือก ลูกค้าระดับเดิมยังพบได้ในบทถัดไป ลูกค้าที่รอพร้อมกันจะไม่ซ้ำตัวละคร

### ตัวละครและสีหน้า

| ระดับ | ลูกค้า |
|---|---|
| Common | คุณยายแม่มดสมุนไพร, จอมเวทฝึกหัด, สาวน้อยเก็บเห็ด, ชาวนาท้องถิ่น |
| Rare | อัศวินรับจ้าง, โจรเงาพเนจร, นักพิทักษ์ป่าเอลฟ์, นักการค้าแดนไกล |
| Epic | นักรบเบอร์เซิร์กเกอร์, นักบวชศักดิ์สิทธิ์, อัศวินเกราะดำ |
| Legendary | อาจารย์ใหญ่โรงเรียนเวทมนตร์ (Archmage Albus), ราชินีภูติแห่งป่าลึก |

ภาพลูกค้าเป็น PNG ขนาด **32×32 พิกเซลจริง** ใช้ภาพแม่มดที่ผู้ใช้เลือกเป็นต้นแบบ แล้วลดรายละเอียดลงเหลือรูปทรง เสื้อผ้า และอุปกรณ์ที่บอกตัวละคร ใช้สีไม่เกิน **16 สีต่อคน** ร่วมกันทั้งสามอารมณ์ ไม่มีขอบเบลอหรือพิกเซลกึ่งโปร่งใส แต่ละคนมีความสูงต่างกันและยึดพื้นร่วมกัน ทั้งสามอารมณ์ใช้สเกลเดียวกัน ตัวปิดหน้า เช่น โจรเงาและอัศวินเกราะดำ แสดงความโกรธด้วยดวงตา ท่ากำหมัด และท่าทางของช่วงไหล่ร่วมด้วย

- **ปกติ (`normal`)**: ความอดทนเหลือมากกว่า 50%
- **เริ่มไม่พอใจ (`impatient`)**: เหลือมากกว่า 25% ถึง 50%
- **โกรธ (`angry`)**: เหลือ 25% หรือน้อยกว่า โดยลูกค้ายังรอและเสิร์ฟได้ จนความอดทนเป็นศูนย์จึงเดินออก

สถานะคำนวณจากความอดทนที่เหลือจริงของแต่ละคน จึงรวมอัตราลดตามระดับ นิสัย และผลจากการปรุงพลาด การพักเกมหรือเปิดตำราจะหยุดทั้งเวลาและการเปลี่ยนสีหน้า สมุดลูกค้าบนแผนที่แสดงทั้ง 39 ภาพเทียบกัน

ไฟล์ภาพแยกคนละ 3 ภาพ:

- `asset/customers/<character>/normal.png`, `impatient.png`, `angry.png`: 39 PNG พื้นหลังโปร่งใสที่เกมใช้งานจริง
- `output/customers/white/`: 39 PNG พื้นหลังขาว แยกชื่อคนและสีหน้า เช่น `elder_herbalist-normal.png`
- `output/customers/customers-white-39.zip`: ชุดพื้นหลังขาว 39 ภาพ
- `output/customers/customers-transparent-39.zip`: ชุดโปร่งใส 39 ภาพ แยกโฟลเดอร์คนละ 3 ภาพ
- `output/customers/all-customers-three-expressions.png`: ภาพรวมพร้อมชื่อและระดับ
- `output/customers/customer-atlas.png`: แอตลาสโปร่งใส แถวละหนึ่งคน คอลัมน์ปกติ / ไม่พอใจ / โกรธ ตามลำดับ enum
- `output/customers/manifest.csv`: ชื่อไทย อังกฤษ ระดับ ความสูง สีหน้า และตำแหน่งไฟล์

`CustomerSprites` โหลด PNG 32×32 ที่เกมใช้จริง `ExportCustomerSprites` สร้างชุดพื้นหลังขาว ภาพรวม และ ZIP ใหม่ทุกครั้งที่ build โดยไม่เขียนทับภาพลูกค้าที่เกมใช้ หากต้องจัดเฟรมใหม่ ใช้ `PrepareCustomerArtwork` ซึ่งแยกแถบต้นฉบับที่ออกแบบด้วยรูปทรงเรียบง่ายสำหรับสไปรต์ขนาดเล็กเป็นสามเฟรม จัดเป็น 32×32 และใช้พาเลต 16 สีร่วมกันทั้งสามภาพ ต้นฉบับล่าสุดอยู่ใน `output/imagegen/customer-sources/native32/` แหล่งภาพและพรอมป์ต์อยู่ในโฟลเดอร์เดียวกัน การ build และเล่นเกมไม่ต้องใช้เครือข่ายหรือไลบรารีภายนอก

วัตถุดิบทั้งแปด: เกล็ดมังกร, หยดน้ำตานางเงือก, เกสรดอกสุริยัน, เห็ดเรืองแสง, กลีบดอกเหมันต์, ละอองแสงจันทร์, รากไม้พันปี และคริสตัลสีรุ้ง

## โครงสร้าง OOP

ซอร์สอยู่ใน `src/com/potioncraft/`:

- `model/customer/Customer` เป็น abstract class ที่ห่อหุ้มความอดทนและสถานะลูกค้า มี `CommonCustomer`, `RareCustomer`, `EpicCustomer`, `LegendaryCustomer` สืบทอดและคำนวณรางวัล/อัตราหมดความอดทนต่างกันผ่าน polymorphism
- `CustomerProfile` ประกอบนิสัยและข้อมูลตัวละครทั้ง 13 คนเข้ากับคลาสระดับลูกค้า `CustomerFactory` สร้างลูกค้าโดยใช้สูตรที่ปรุงได้ในด่าน
- `model/potion/Ingredient`, `Potion`, `RecipeBook`, `Cauldron` แยกวัตถุดิบ สูตร ขวดยา และหม้อปรุง องค์ประกอบสูตรและรายการลูกค้าส่งออกเป็นรายการที่แก้ไขโดยตรงไม่ได้
- `model/game/Level` เป็นข้อมูลด่านที่ไม่เปลี่ยนระหว่างเล่น `SkillCheck` เก็บกติกามินิเกม `CampaignProgress` ดูแลการบันทึกดาว
- `GameEngine` เป็นตัวประสานตรรกะเกมที่เขียนเองทั้งหมด ชื่อคลาสนี้ไม่ได้หมายถึงการใช้เอนจินเกมภายนอก มี `GameEventListener` สำหรับ observer และแยกการจำลองออกจากภาพ
- `ui/PotionGamePanel` วาดหน้าจอและรับอินพุต `PixelArt` วาดภาพพิกเซล `PotionShopGUI` เป็นหน้าต่าง Swing ส่วน `audio/SoundManager` สังเคราะห์เสียงด้วย Java Sound

ใช้เฉพาะ Java standard library ไม่ใช้ Unity, Godot, libGDX, Phaser หรือเอนจินเกมอื่น ตัวเกมใช้ `PotionGamePanel` เป็นหน้าจอหลัก และ `PixelArt` วาดลูกค้า สมุนไพร หม้อ และขวดยา

ฉากและพื้นที่คลิกปรับขนาดพร้อมกันโดยคงสัดส่วนเกม เมื่อย่อหน้าต่างหรือใช้จอกว้างจะมีขอบเพิ่มเพื่อไม่ให้ภาพยืด

## บันทึกและการทดสอบ

ดาวอยู่ใน `save/progress.properties` ภายใต้โฟลเดอร์ทำงาน เก็บเฉพาะสถิติสูงสุดและปลดล็อกด่าน ไม่บันทึกเกมที่เล่นค้าง ใช้ไฟล์ชั่วคราวแล้วแทนที่ไฟล์บันทึกเพื่อลดปัญหาเขียนไม่ครบ หากบันทึกไม่ได้ เกมจะแสดงข้อความบนแผนที่และหน้าผลลัพธ์

เซฟจากเวอร์ชัน 40 ด่านจะนำดาวของด่านย่อย 1–5 ในแต่ละบทมาใช้กับแผนที่ใหม่ โดยคงหมายเลขบทเดิมไว้

คอมไพล์และทดสอบโดยเปิด PowerShell ในโฟลเดอร์เกม:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\test.ps1
```

ชุดทดสอบไม่ใช้ไลบรารีเพิ่มและไม่เปิดหน้าต่าง:

- `GameLogicTest`: ตรวจสูตร ลำดับวัตถุดิบ ความอดทน และรางวัลของคลาสลูกค้า
- `CampaignTest`: เล่นผ่าน 20 ด่านด้วยการใส่สมุนไพร ผ่านสกิลเช็ค และเสิร์ฟจริงผ่าน API ของเกม ตรวจ 8 วัตถุดิบ, 24 สูตร, ลูกค้า 4/4/3/2, สูตรที่ปรุงได้, การหยุดเวลา, ยาพัง, การปลดล็อก และโหลดบันทึก 60 ดาว
- `AssetLoadingTest`: ตรวจภาพฉาก 3 ชิ้นและ PNG ลูกค้า 39 ภาพ รวมการรันแบบ IDE และ JAR จากโฟลเดอร์อื่นที่มีภาพเก่าชื่อซ้ำ ตรวจว่าทุกพิกเซลตรงกับภาพล่าสุดในโปรเจกต์
- `CustomerSpriteTest`: ตรวจ 39 PNG และชุด ZIP ขนาด 32×32 พาเลตสีจำกัด พื้นหลังโปร่งใส ความสูงต่างกัน พื้นตรงกัน ขนาดคงที่ระหว่างสีหน้า การเปลี่ยนสีหน้าตามเวลารอ และการหยุดสีหน้าเมื่อพักเกม
- `VisualSmokeTest`: วาด Swing จริงเป็น PNG ตรวจฉากกับเคาน์เตอร์ซ้อนทับลูกค้า คลิกสมุนไพรทั้ง 6 ช่องเมื่อย่อหน้าต่าง ลูกค้า 4 คนพร้อมกัน การเสิร์ฟด้วยเมาส์ ปุ่มปรุง และการหยุดเวลาเมื่อเปิดตำรา รวม 16 ภาพใน `build/screenshots/`

ข้อมูลทดสอบใช้ไฟล์ใน `build/` แยกจากเซฟที่ใช้เล่นจริง ผลการจำลองพิสูจน์ว่าทุกด่านผ่านสามดาวได้ แต่ความยากสำหรับผู้เล่นจริงยังปรับแต่งต่อได้

## แผนที่กระดาษม้วน
หน้าเลือกด่านใช้ภาพกระดาษม้วนตามภาพอ้างอิง ไม่มีหัวเรื่องด้านบน มีป่ารุ่งอรุณ ท่าเรือจันทรา ถ้ำผลึก และพระราชวังมังกร สถานที่ละ 5 ด่าน รวม 20 ด่าน เก็บดาวและปลดล็อกตามลำดับเดิม ภาพอยู่ใน asset/map/ และบรรจุใน JAR สำหรับเล่นออฟไลน์ ภาพ forest.png, harbor.png, cave.png และ palace.png เป็น PNG โปร่งใสแยกไฟล์ ส่วน parchment.png เป็นพื้นหลังกระดาษที่ไม่มีชื่อ รวมดาวน์โหลดใน output/map/map-assets.zip และบันทึกคำสั่งสร้างภาพใน output/map/prompts.txt

ปรับผังแผนที่ให้สถานที่มีขนาดไม่เกิน 190×130 และวางเหลื่อมกัน จุดเลือกด่านทั้ง 20 จุดเรียงไปตามถนนโค้งคดเคี้ยว มีลายเส้นภูเขา ปากถ้ำ ต้นไม้ และคลื่นน้ำสีน้ำตาลจางวาดด้วย Java2D เพื่อให้กลมกลืนกับกระดาษ ภาพสถานที่แยกยังใช้ไฟล์ PNG เดิมใน asset/map/

การเลือกด่าน: คลิกภาพป่า ท่าเรือ ถ้ำ หรือพระราชวังบนแผนที่ เพื่อเปิดหน้าต่างเลือกด่านเฉพาะสถานที่นั้น 5 ด่าน แต่ละด่านแสดงดาวสะสมและสถานะปลดล็อก กดด่านที่เปิดแล้วเพื่อเข้าเตรียมร้าน กดกลับแผนที่หรือ ESC เพื่อปิดหน้าต่าง จุดด่านทั้ง 20 จุดไม่แสดงบนแผนที่หลักแล้ว

วัตถุดิบในตู้แสดงเป็นกองซ้อนเอียง มีชิ้นกลางคมชัดพร้อมจำนวนคงเหลือ ใช้ไป 3 ชิ้นเหลือ 2 ชิ้น ใช้ครบ 5 ชิ้นช่องจะว่าง กดช่องหรือเลข 1–6 เพื่อเริ่มเติม 3 วินาที ระหว่างเติมใช้ช่องอื่นหรือปรุงยาได้ การพักเกมและเปิดตำราหยุดเวลาเติมด้วย เริ่มด่านใหม่จะเติมเต็มทุกช่อง การเททิ้งไม่คืนวัตถุดิบ
